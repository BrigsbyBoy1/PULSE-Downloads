# PULSE downloads

PULSE is a flexible performance-monitoring app for gaming. Choose the readings you want, resize the dashboard to fit your space, and use saved profiles for different situations.

**[Download the latest PULSE release](https://github.com/BrigsbyBoy1/PULSE-Downloads/releases/latest)**

Prebuilt packages are available for Windows x64, Apple silicon and Intel Macs, Linux x64 and ARM64, and Steam Deck / SteamOS through Decky. Each download includes installation instructions and license notices. No build tools are required.

Use a platform app archive from the release assets. GitHub's automatic **Source code** archives contain this download repository's documentation, not the app.

This repository hosts public downloads only. PULSE's development repository and beta bug reports remain private. The Decky package includes its runnable plugin files and the build-source materials required by its dependencies. Invited testers can use **Report a problem** in PULSE to open the private feedback form.
